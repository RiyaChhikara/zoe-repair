# Zoe

A one-page field guide: how repairable is your phone?

Open `index.html`, or publish this folder with GitHub Pages. Share a result with `?phone=fairphone-6` or a quiz link created from the result screen.

Zoe is an independent estimate. It is not an iFixit score. Official smartphone repairability scores are published by [iFixit](https://www.ifixit.com/repairability/smartphone-repairability-scores).
